# 📚 Lista de Exercícios 01, 02 e 03 — Java

Repositório criado para registrar minha evolução nos estudos de **Java**, com foco nos fundamentos da linguagem, entrada e saída de dados, processamento de cálculos, estruturas de decisão e estruturas de repetição.

Os exercícios foram desenvolvidos de forma progressiva, começando por operações básicas e avançando para estruturas condicionais e estruturas de repetição.

# 📝 Lista 01 — Fundamentos

A primeira lista é focada nos fundamentos básicos da programação em Java.

### Conteúdos praticados:

1. Entrada de dados e apresentação de informações
2. Operações matemáticas
3. Conversão de reais para dólares
4. Média de quatro notas
5. Cálculo de salário bruto, INSS e salário líquido
6. Área e perímetro de um círculo
7. Área, perímetro e diagonal de um retângulo
8. Conversão de Celsius para Fahrenheit e Kelvin
9. Verificação de número par ou ímpar
10. Classificação de notas
11. Identificação do maior entre três números
12. Cálculo de conta de energia por faixa de consumo

### Conteúdos praticados:

7. Saudação de acordo com o horário
8. Infração por excesso de velocidade
9. Cálculo de bônus por tempo de empresa
10. Validação de usuário e senha
11. Verificação de frequência e nota

13. Calculadora com `switch`
14. Identificação da quantidade de dias de um mês

# 🔄 Lista 03 — Estruturas de Repetição

A terceira lista introduz estruturas de repetição, permitindo executar um determinado bloco de código várias vezes.

### Conteúdos praticados:

* `while`
* `do-while`
* `for`
* Contadores
* Acumuladores
* Sentinelas
* Laços aninhados
* Validação de entrada
* Repetição controlada por condição
* Repetição controlada por quantidade
* Integração entre repetição e estruturas de decisão

### Exercícios:

1. Imprimir valores de `1` até `N` usando `while`
2. Tabuada usando `while`
3. Validação de nota usando `do-while`
4. Menu de operações usando `do-while` e `switch`
5. Soma dos números pares de um intervalo usando `for`
6. Cálculo de fatorial usando `for`
7. Média da turma utilizando contador e acumulador
8. Leitura de valores utilizando uma sentinela
9. Tabuadas utilizando laços aninhados
10. Sistema de caixa de supermercado integrando repetição, decisão e acumuladores
